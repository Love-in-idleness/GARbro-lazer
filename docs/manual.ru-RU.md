# Руководство GARbro

GARbro открывает игровые архивы, показывает их содержимое и извлекает ресурсы. Установите .NET 11 Runtime для вашей архитектуры перед запуском обычного настольного пакета. Flatpak и Microsoft Store уже содержат среду выполнения. Для самоподписанного MSIX сначала доверьтесь сертификату из того же выпуска.

## Вкладки

GARbro использует одно главное окно. Каждый открытый или перетащенный файл либо каталог получает отдельную вкладку; повторное открытие ресурса выбирает существующую. Повторный запуск и «Открыть с помощью» передают файлы в уже открытое окно. Вкладки сохраняют путь, историю, поиск и выделение.

Ctrl/Cmd+T создаёт вкладку, Ctrl/Cmd+W закрывает её, Ctrl+Tab / Ctrl+Shift+Tab переключают вкладки. Сочетания можно изменить в настройках. При переключении воспроизведение останавливается; закрытие последней вкладки возвращает начальную страницу. Адресная строка открывает путь в текущей вкладке.

## Просмотр

Откройте файл или папку в меню «Файл», либо перетащите их в окно. Двойной щелчок открывает папку или вложенный архив. Кнопки «Назад», «Вперёд» и «На уровень выше» позволяют вернуться. Открытие не изменяет исходные файлы.

Используйте поиск, сортировку, выбор всех файлов или выбор по маске. В контекстном меню можно назначить тип ресурса, скопировать имена или показать исходный файл в файловом менеджере. Если архиву нужны соседние индексы или ключи, откройте всю родительскую папку.

Установленные DEB, MSIX, Flatpak и приложение macOS добавляют GARbro в список «Открыть с помощью». Выберите его в файловом менеджере и, если нужно, назначьте приложением по умолчанию. Установка сама не меняет ваши настройки. Для DAT/BIN приложение также может появляться среди обработчиков неизвестных двоичных файлов. Переносимые ZIP/TAR не регистрируются.

## Извлечение и преобразование

«Извлечь всё» и «Извлечь выбранное» позволяют выбрать выходную папку, обработку конфликтов и преобразование изображений или звука. Рекурсивная распаковка обходит вложенные папки и архивы. Копии вложенных архивов обычно сохраняются рядом с папками `имя-архива.unpacked`.

Параметры удаления вложенных архивов и исходных форматов медиа относятся только к выходным копиям после успешной обработки. При ошибке, пропуске или достижении ограничения копии сохраняются. Исходные файлы игры не удаляются. Отмена сохраняет готовые результаты и удаляет незавершённые временные файлы.

«Создать архив» использует выбранные файлы и папки, а без выбора — текущую папку. Выберите доступный для записи формат и его параметры. «Пакетное преобразование» сохраняет новые изображения или аудиофайлы в указанное место. Перемещение физических файлов в системную корзину требует подтверждения.

## Предпросмотр

Изображение можно вписать в область просмотра или показать в исходном размере. Для текста доступны перенос строк, страницы и копирование. В списке «Кодировка предпросмотра / HEX» выберите HEX, чтобы увидеть смещения, байты и ASCII любого файла страницами до 64 КиБ. Этот выбор действует только на текущий файл, не меняет кодировку имён и останавливает медиа.

Аудио и видео запускаются только кнопкой «Воспроизвести». Доступны пауза, остановка, перемотка и громкость. Переключение файла останавливает воспроизведение и очищает кэш. Без аудиоустройства видео воспроизводится без звука. В Linux нужны системные SDL2 и FFmpeg; пакеты Windows/macOS содержат видеодекодер. Поддержка конкретного кодека зависит от декодера.

## Настройки и сочетания клавиш

В настройках доступны English, 简体中文, Русский, 日本語 и системный язык. Выбор сохраняется и сразу применяется. Язык интерфейса не влияет на кодировку файлов. Для неверных имён или текста измените кодировку в разделе «Декодирование»; поля с кодировкой, заданной форматом, сохраняют её.

Можно выбрать светлую, тёмную или системную тему, выходную папку и лимиты времени/памяти. Пароли и ключи остаются в текущем сеансе.

В разделе «Сочетания клавиш» найдите команду, нажмите «Записать сочетание», нажмите нужные клавиши и добавьте запись. У команды может быть несколько сочетаний. Удалите все записи, чтобы отключить сочетание; восстановите одну команду или все значения по умолчанию. Конфликты нужно устранить перед сохранением. Редактирование текста и методы ввода имеют приоритет.

По умолчанию Ctrl+O открывает файл, Ctrl+P открывает настройки, Ctrl+Q завершает работу. F3 упаковывает выбранное, F4 извлекает выбранное, F5 обновляет список, F6 запускает преобразование. Enter открывает выбранное, Backspace или Ctrl+PageUp переводит выше, Alt+Left/Right — по истории. В macOS вместо Ctrl используется Command.

## Командная строка

CLI находится в папке `cli`; DEB также устанавливает команду `garbro`. В PowerShell используйте `.\garbro.exe` вместо `./garbro`.

```sh
./garbro --language ru-RU help
./garbro list "data.xp3" --scheme none
./garbro extract "data.xp3" --scheme none -o "output"
./garbro extract "game-data" --recursive --nested -o "output" --encoding shift_jis
./garbro convert "image.tlg" -o "image.png"
```

`--language` можно указывать до или после команды. По умолчанию используется системный язык. Имена команд, полей JSON, коды ошибок и числовые данные не переводятся. `--scheme none` предназначен для незашифрованного XP3. Для зашифрованных ресурсов нужны правильные `--scheme` или `--options`. `--overwrite skip` пропускает существующие файлы, `replace` заменяет их; по умолчанию конфликт считается ошибкой.

## Справка

Меню «Справка» содержит руководство, решение проблем, лицензии, проверку обновлений, экспорт журналов и сведения о программе. Список зарегистрированных форматов не означает проверку всех вариантов игр. Проверка обновлений выполняется только по запросу. Отчёты и журналы не отправляются автоматически.

В Flatpak выбирайте файлы и папки системным диалогом. Для соседних индексов разрешите доступ ко всей исходной папке. Песочница не предоставляет системную команду корзины.


### Область извлечения и форматы

Сначала выберите элементы и нажмите «Извлечь выбранное» (F4). «Извлечь всё» обрабатывает текущую папку, включая скрытые поиском элементы. Рекурсия включается в окне извлечения и охватывает вложенные папки и архивы только в выбранной области, без соседних файлов.

Для изображений, аудио, видео и сценариев доступны отдельные форматы. Чтобы при извлечении получить редактируемый .tsc из .gsc, выберите «Экспорт редактируемого текста» в поле «Формат сценария». Аудио: автоматический стандартный формат, WAV, FLAC, M4A, а в настольной версии также Ogg Vorbis, Opus и AIFF. Видео: MP4 или MKV без перекодирования потоков. «Исходный формат» означает копирование без преобразования. Обычные файлы записываются в выходную папку, архивы — в одноимённые папки `.unpacked`.

Удаление оригинального формата и вложенных архивов касается только выходных копий. Файлы игры не изменяются. При сбое отображается список элементов и сохраняются доступные для восстановления копии. Сообщение об отсутствии подходящих файлов не означает успешное извлечение. Пакетное преобразование использует те же форматы.

## WebP и преобразование из командной строки

При извлечении или пакетном преобразовании выберите **WebP (без потерь)** в формате изображений. Прозрачность сохраняется. Результат отдельно показывает преобразованные, пропущенные и неудачные файлы; типы с исходным форматом пропускаются. Создание архивов, извлечение и преобразование используют выбор на момент запуска команды.

`garbro convert image.png -o image.webp` выбирает WebP по расширению выхода. Так же работают WAV, FLAC, M4A, MP4 и MKV. Параметры преобразования при извлечении перечислены в `garbro extract --help`: `--image-format webp`, `--audio-format wav`, `--video-format mp4`, `--discard-original-media`, `--discard-child-archives`. Последний требует `--nested`. Исходные файлы сохраняются.

## Преобразование сценариев

Выберите поддерживаемый сценарий на диске или в архиве, откройте «Преобразовать» и выберите экспорт редактируемого текста в поле «Формат сценария».

- CodeX RScript GSC → TSC в UTF-8 и Ren’Py RPYC/RPYMC → RPY/RPYM обрабатываются встроенными средствами.
- Текстовые KS и TJS движка KiriKiri → UTF-8. Байткод TJS2100 преобразуется в читаемый TJS встроенным Furikiri Core.
- Сценарии BGI/Ethornell v1 (`._bs` или без расширения) → BSD, а `._bp` → BPD встроенными средствами. В автоматическом режиме используется CP932. Можно выбрать GBK.
- NScripter `nscript.dat` → TXT. В автоматическом режиме проверяются BOM и UTF-8, затем используется CP932. Для файлов в GBK выберите GBK.
- Artemis AST → UTF-8, ASB → структурированный JSON. Unity Utage `data.dsm` → TXT. RPG Maker XP/VX/VX Ace `Scripts.rxdata`, `Scripts.rvdata`, `Scripts.rvdata2` → редактируемый JSON RGSS или исходный код Ruby. Luca System `SCRIPT.PAK` → редактируемый JSON Luca с выбранной схемой игры.

Обработка сценариев работает автономно, без дополнительных утилит. В поле формата вывода сценария выберите экспорт для формата по умолчанию или исходный код Ruby для RGSS. Для обратной сборки JSON выберите RGSS или LUCA; сохраняйте записи и метаданные, изменяя текстовые значения. Luca запросит схему игры, например LOOPERS. Для Ren’Py и скомпилированного TJS пока доступен только экспорт. Неподдерживаемый вариант вызывает ошибку без изменения предыдущего результата.
```sh
garbro convert Scripts.rvdata2 -o Scripts.rvdata2.rgss.json
garbro convert Scripts.rvdata2.rgss.json -o Scripts.rvdata2 --to RGSS
garbro convert Scripts.rvdata2 -o scripts.rb --to RB
garbro convert SCRIPT.PAK -o SCRIPT.PAK.luca.json --scheme LOOPERS
garbro convert SCRIPT.PAK.luca.json -o SCRIPT.PAK --to LUCA
```


Команда `garbro convert scene.gsc -o scene.tsc --encoding gbk` явно задаёт GBK. В режиме «Авто» GSC/BGI используют CP932. Для файла внутри архива используйте `garbro convert scripts.rpa --entry game/script.rpyc -o script.rpy`. Имя файла внутри архива показывает `garbro list`.

`--recursive` обходит папки диска; `--nested` раскрывает вложенные архивы. Обычный обход пропускает неопознанные файлы и сохраняет относительные папки. Общие параметры можно поставить перед командой; `--` защищает имена файлов, начинающиеся с дефиса. Старый способ извлечения одного архива и поля JSON сохранены.

## Создание архивов

На панели инструментов, в меню обработки ресурсов или в контекстном меню выберите **Упаковать выбранное** (F3) или **Упаковать всё**. Вторая команда включает элементы текущей папки, скрытые фильтром поиска. Обе команды включают вложенные папки. Выберите формат записи и выходной файл, затем при необходимости раскройте **Параметры формата архива**.

Преобразование изображений, аудио, видео и сценариев необязательно. По умолчанию сценарии сохраняются без преобразования. Для отредактированного сценария можно выбрать формат компиляции. Параметр **Не включать исходные файлы после преобразования** помещает в архив только преобразованные версии затронутых файлов. Остальные файлы включаются как обычно, а исходники сохраняются на диске. Аудио AUTO без перекодирования включается один раз. Ошибка преобразования или совпадение имён отменяет создание архива и сохраняет предыдущий выходной файл.

```sh
garbro create "assets" -o "data.xfl"
garbro create "assets" -o "data.zip" --image-format webp --audio-format wav --discard-original-media
garbro create "assets" -o "data.xp3" --format XP3 --scheme none
```

Параметры записи, кодировки, замены и ограничения описаны в `create --help`. Для одной папки используются её содержимое, для нескольких входов — пути от общего родителя. Доступны существующие форматы записи. Чтение преобразованных медиа зависит от движка; ссылки в сценариях не меняются. При работе из командной строки скомпилируйте сценарии командой `garbro convert` перед упаковкой.

## Компиляция сценариев (1.1.2)

Выберите отредактированные файлы и откройте преобразование и выберите «Формат сценария». Чтобы пропустить сценарии, выберите «Не преобразовывать сценарии». Для TSC выберите GSC, для BSD — BGI, для BPD — BGI-BP, для полного JSON ASB — ASB. Текст можно скомпилировать в NSCRIPT (`nscript.dat`) или DSM (`data.dsm`). Используются прежние промежуточные форматы; JSON только с репликами ASB не подходит.

Шесть компиляторов встроены в GARbro и работают на компьютере и Android без Python и внешнего компилятора. Исходный текст должен быть в UTF-8 или Unicode с BOM. Выбор кодировки влияет на строки результата: автоматически используются CP932 для GSC/BGI/NScripter и UTF-8 для ASB; DSM всегда использует UTF-8. Непредставимые символы вызывают ошибку. Внешнюю таблицу `#string_table` нужно объединить с BSD. Неизвестные варианты GSC экспортируются как исходные байты с контрольной суммой: их можно восстановить, но не переводить.

```sh
garbro convert edited.tsc -o scene.gsc --encoding shift-jis
garbro convert edited.bsd -o scene --to BGI
garbro convert edited.bpd -o scene._bp --to BGI-BP
garbro convert edited.json -o scene.asb
garbro convert edited.txt -o nscript.dat --to NSCRIPT --encoding gbk
garbro convert edited.txt -o data.dsm --to DSM
```

Выберите отдельную выходную папку. Исходные файлы не меняются; ошибка сохраняет предыдущий результат. Несколько текстов, создающих один `nscript.dat` или `data.dsm`, преобразуйте отдельно. Компиляция не меняет движок и не гарантирует поддержку нового набора символов.

## Сборка Android для разработки

Требуется Android 12 или новее. Для большинства телефонов и планшетов подходит APK ARM64; для эмулятора x86 — x64. Установите APK системным установщиком и предоставьте доступ через системный выбор файлов/папок. Используются общий интерфейс с вкладками, фоновая служба декодирования и системный медиаплеер Android. Встроенная обработка сценариев доступна на Android; преобразование медиа через FFmpeg недоступно. APK из CI предназначены для разработки, ещё не опубликованы в F-Droid/IzzyOnDroid. Пакет с временным ключом не обновит установку с другой подписью.

Настольная версия 1.1.2 использует .NET 11. Store и Flatpak включают среду выполнения; для остальных настольных пакетов установите .NET 11 Runtime соответствующей архитектуры.

## Выбор формата и предпросмотр

Выберите **Открыть с указанием формата…** в меню файлов или в контекстном меню одного файла на диске. Декодеры архивов и изображений можно искать по названию, тегу или расширению. Выбор сохраняется во вкладке. Тот же файл можно открыть в другой вкладке с автоопределением. Форматы вложенных архивов определяются автоматически.

Для поддерживаемых скриптов выберите **Декомпилированный текст**. Результат можно просматривать по страницам и копировать. В режиме HEX нажмите **Перейти к смещению…** и вставьте шестнадцатеричный адрес из начала строки с префиксом `0x` или без него. Выбрав выходной формат изображения в пакетном преобразовании (F6), можно применить смещение изображения к холсту.

В разделе **Справка → Проверить обновления** выберите **Импортировать локальную базу схем…**, чтобы загрузить экспорт SchemeTool `.json` или `.json.gz` без сети. Проверенная внешняя база применяется поверх встроенной. При ошибке импорта продолжает действовать прежняя база.
