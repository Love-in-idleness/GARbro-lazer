# GARbro-lazer 1.1.3

## 简体中文

- 打开归档后，可在「高级选项 → 游戏方案」中搜索并选择预设。确认后重新加载当前归档并刷新预览。需要解码参数时的弹窗也提供同一列表。
- `Fate/hollow ataraxia` 的 XP3 可通过同目录下的 `FateFD.exe` 自动识别方案。若单独提取的 TLG 仍含加密数据，请从原 XP3 打开并选择游戏方案。
- 桌面端的提取、转换和封包默认使用源文件所在目录。设置里的默认输出目录优先。归档继续展开为同名 `.unpacked` 子目录。
- 封包窗口现有图像、音频、视频和脚本四个输出选项。可直接回编已编辑的脚本并将结果入包，也可以选择 WCG 等已有可写图像格式。脚本默认不转换，TLG 支持读取。

普通桌面包需要对应架构的 [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0)，Store 和 Flatpak 自带运行时。Microsoft Partner Center 请上传 **`garbro-1.1.3-store.msixupload`**。Android APK 为开发签名预览版。使用 **SHA256SUMS** 核对下载。[安装说明](https://github.com/Love-in-idleness/GARbro-lazer/blob/v1.1.3/docs/install.md) · [使用说明](https://github.com/Love-in-idleness/GARbro-lazer/blob/v1.1.3/docs/manual.zh-CN.md)

## English

- Search and choose a preset under **Advanced options → Game scheme**. Confirming reloads the current archive and refreshes its preview. The decoder parameters dialog uses the same list.
- XP3 archives from `Fate/hollow ataraxia` can detect their scheme from a sibling `FateFD.exe`. If an extracted TLG still contains encrypted data, open its original XP3 and select the game scheme there.
- Desktop extraction, conversion, and archive creation default to the source folder. A configured output directory takes precedence. Archives still expand into a folder ending in `.unpacked`.
- The archive creation dialog includes image, audio, video, and script outputs. Recompile edited scripts while packing and choose from writable image formats such as WCG. Script conversion is off by default. TLG images can be read.

Regular desktop packages require the matching [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0). Store and Flatpak include it. Upload **`garbro-1.1.3-store.msixupload`** to Microsoft Partner Center. Android APKs are development-signed previews. Verify downloads with **SHA256SUMS**. ## Русский

- В разделе **Дополнительные параметры → Схема игры** можно найти и выбрать готовую схему. После подтверждения архив и предпросмотр обновляются. Такой же список есть в диалоге параметров декодирования.
- Схема XP3 для `Fate/hollow ataraxia` определяется по файлу `FateFD.exe` в той же папке. Если извлечённый TLG остался зашифрованным, откройте исходный XP3 и выберите схему игры.
- Настольное приложение по умолчанию извлекает, преобразует и упаковывает файлы в исходной папке. Выбранная в настройках папка имеет приоритет. Архивы извлекаются в подпапку с суффиксом `.unpacked`.
- При создании архива можно выбрать форматы изображений, аудио, видео и сценариев. Доступны компиляция отредактированных сценариев и запись WCG. По умолчанию сценарии сохраняются без преобразования. Изображения TLG доступны для чтения.

Обычным настольным пакетам нужна [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0) соответствующей архитектуры. Store и Flatpak включают её. Для Microsoft Partner Center предназначен **`garbro-1.1.3-store.msixupload`**. APK Android подписаны ключом разработки. Проверяйте загрузки по **SHA256SUMS**. ## 日本語

- **詳細オプション → ゲームの設定**から登録済みの設定を検索して選べます。確定すると現在のアーカイブとプレビューが更新されます。復号に必要な設定を求める画面でも同じ一覧を使えます。
- `Fate/hollow ataraxia` の XP3 は、同じフォルダーにある `FateFD.exe` から設定を自動判定できます。抽出した TLG が暗号化されたままの場合は、元の XP3 を開いてゲームの設定を選んでください。
- デスクトップ版では抽出、変換、アーカイブ作成の既定の出力先が入力元のフォルダーになります。設定に出力先を指定している場合はそちらが優先されます。アーカイブは引き続き `.unpacked` フォルダーに展開されます。
- アーカイブ作成時に画像、音声、動画、スクリプトの出力形式を指定できます。編集したスクリプトの再コンパイルと WCG などの画像出力に対応します。既定ではスクリプトを変換しません。TLG は読み込みに対応します。

通常のデスクトップ版には対応する [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0) が必要です。Store・Flatpak 版はランタイムを同梱します。Microsoft Partner Center には **`garbro-1.1.3-store.msixupload`** を提出してください。Android APK は開発用署名のプレビューです。**SHA256SUMS** でダウンロードを確認してください。[インストール](https://github.com/Love-in-idleness/GARbro-lazer/blob/v1.1.3/docs/install.md) · [使用説明](https://github.com/Love-in-idleness/GARbro-lazer/blob/v1.1.3/docs/manual.ja-JP.md)
