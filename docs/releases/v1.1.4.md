# GARbro 1.1.4

## 简体中文

- CLI 提取保护源归档，在写入前检查批量目标目录冲突。单归档直接写入 `-o`，递归和转换使用相同的 JSON 结果字段。
- 指定格式探测严格使用所选解码器。提取可同时指定解码器、递归和转换。支持转换归档内的图像、音频和视频，并报告输出是否写入。
- `extract` 和 `create` 支持 `--script-format`。`convert` 和图像提取支持 `--adjust-offset`。CLI 可保存本地方案库，视频输出可用 `formats --type video` 查询。
- GUI 可在帮助中导入方案库，以指定格式打开磁盘归档或图片，预览反编译脚本，跳转 HEX 偏移，并在 F6 转换中应用图像偏移。
- 桌面工具栏和菜单分别提供提取、封包所选与全部的操作。搜索、预览和回收站确认与当前选择保持同步。

## English

- CLI extraction protects input archives and detects duplicate batch destinations before writing. A single archive extracts directly to `-o`, and every extraction mode uses the same JSON fields.
- An explicit input reader is honored by probing and works with recursive extraction and conversion. Archive entries can be converted directly, and conversion reports whether it wrote the output.
- Use `--script-format` with extraction or packing, and `--adjust-offset` when converting images. The CLI can save a local scheme database and list video outputs with `formats --type video`.
- The desktop UI imports scheme databases from Help, opens disk files with a chosen reader, previews decompiled scripts, jumps to HEX offsets, and applies image offsets during batch conversion.
- The toolbar and menus expose selected and all scopes for extraction and packing. Search, previews, and recycle-bin confirmation follow the current selection.

## Русский

- CLI защищает исходные архивы и проверяет коллизии папок до записи. Один архив извлекается прямо в `-o`. Формат отчёта JSON одинаков во всех режимах.
- При распознавании применяется явно выбранный декодер. Он также работает при рекурсивном извлечении и преобразовании. Элементы архива можно преобразовать напрямую, а отчёт указывает, записан ли файл.
- Параметр `--script-format` доступен при извлечении и упаковке, а `--adjust-offset` применяется к изображениям. CLI сохраняет локальную базу схем и показывает форматы видео по команде `formats --type video`.
- В интерфейсе доступны импорт базы из справки, открытие файлов с заданным декодером, предпросмотр декомпиляции, переход по смещению HEX и учёт смещения изображения при пакетном преобразовании.
- На панели и в меню раздельно доступны извлечение и упаковка выбранного или всех элементов. Поиск, предпросмотр и подтверждение удаления учитывают текущее выделение.

## 日本語

- CLI は入力アーカイブを保護し、書き込み前に一括出力先の重複を検出します。アーカイブ 1 個は `-o` に直接抽出し、すべての抽出モードで同じ JSON 項目を使います。
- 形式指定は識別にも適用され、再帰抽出や変換と併用できます。アーカイブ内の項目を直接変換でき、出力を書き込んだかどうかが分かります。
- 抽出とアーカイブ作成では `--script-format`、画像変換では `--adjust-offset` を使えます。CLI でローカルのスキームデータベースを保存でき、`formats --type video` で動画出力を確認できます。
- GUI のヘルプからスキームを読み込めます。形式を指定して開く操作、逆コンパイル結果のプレビュー、HEX オフセット移動、一括変換での画像オフセット適用に対応しました。
- ツールバーとメニューから、選択項目と全項目の抽出・格納を選べます。検索、プレビュー、ごみ箱への移動確認が現在の選択と一致します。
