# GARbro-lazer 1.0.6

## English

- Open multiple files or folders in one window. Each tab keeps its own location, history, search and selection. Opening a resource again switches to its existing tab.
- ExHibit GYU differential images are composited with their base images when available. Added support for METEOR01 archives from Shinju no Yakata.
- The Microsoft Store package shares one set of app files, media tools and a smaller bundled .NET 10 runtime across the GUI, CLI and decoder.

Choose the package for your system and architecture. Portable packages and standalone installers require the matching .NET 10 Runtime. Flatpak and the Microsoft Store submission bundle include .NET. Verify downloads with **SHA256SUMS**.

## 简体中文

- 在同一个窗口打开多个文件或文件夹。各标签页分别保留位置、历史、搜索和选择。再次打开资源时会切换到已有标签页。
- ExHibit GYU 差分图像在找到基底图像时会自动合成。新增《Shinju no Yakata》的 METEOR01 归档支持。
- 微软商店包的界面、命令行和解码进程共用应用文件、媒体工具和经过精简的 .NET 10 运行时。

按系统和处理器选择安装包。便携包和独立安装包需要对应架构的 .NET 10 运行时。Flatpak 和微软商店提交包自带 .NET。下载后可用 **SHA256SUMS** 校验。

## Русский

- Открывайте несколько файлов или папок в одном окне. Каждая вкладка хранит свой путь, историю, поиск и выделение. Повторное открытие ресурса переключает на его вкладку.
- Разностные изображения ExHibit GYU совмещаются с базовым изображением, если оно доступно. Добавлена поддержка архивов METEOR01 из Shinju no Yakata.
- В пакете Microsoft Store интерфейс, CLI и декодер используют общие файлы приложения, мультимедийные инструменты и уменьшенную среду .NET 10.

Выберите пакет для вашей системы и архитектуры. Для переносных пакетов и отдельных установщиков нужна соответствующая среда .NET 10. Flatpak и пакет для отправки в Microsoft Store включают .NET. Контрольные суммы доступны в **SHA256SUMS**.

## Build verification / 构建验证

The bundled Wayland dependency passed its recorded checksum check, and native cursor checks passed on Linux x64 and ARM64. An independent rebuild produced a different hash. [Verification run](https://github.com/Love-in-idleness/GARbro-lazer/actions/runs/43028134695)

随包提供的 Wayland 依赖通过了记录的哈希校验，Linux x64 与 ARM64 的原生光标检查均通过。独立重建产物的哈希仍有差异。 [验证记录](https://github.com/Love-in-idleness/GARbro-lazer/actions/runs/43028134695)

The Flatpak ID stays the same for upgrades. GitHub CI verifies that the old repository URL redirects to GARbro-lazer and applies a local exception for that redirect. Flathub review of the ID is pending.

Flatpak 沿用已有应用 ID 以支持升级。GitHub CI 核对旧仓库地址是否重定向至 GARbro-lazer，并仅对这项重定向使用本地检查例外。该 ID 仍待 Flathub 审核。
