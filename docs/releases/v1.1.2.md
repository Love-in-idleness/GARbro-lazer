# GARbro-lazer 1.1.2

## 简体中文

- 脚本处理进一步内置：Ren’Py 的 `.rpyc`／`.rpymc` 可直接导出为 RPY／RPYM，已编译的 TJS2100 可导出为 TJS，不再需要另外安装 Python、unrpyc 或 tjs2dec。
- RPG Maker XP／VX／VX Ace 的 Scripts 默认导出为一个可编辑的 RGSS JSON，修改后可回编；也可选择只导出 Ruby 源码。保留脚本编号、顺序与名称，修复共享字符串和返回标签处理。
- Luca System 的 `SCRIPT.PAK` 可按游戏方案导出为一个 JSON，再回编为完整归档。内置 11 组方案，修改文本长度后会修正已识别的跳转地址。方案随格式数据库更新，也可通过 SchemeTool 维护。
- 更新中英俄日的界面提示、CLI 帮助、离线说明和转换窗口截图。移除「工具下载」和针对特定壳的检测。GUI 与 CLI 使用相同的内置后端。
- 按上游新方案，将《神樹の館》的 METEOR01 支持移入 AVC 数据库，移除专门写死的解析与文件改名逻辑。保留通用边界校验，原始名称中的输出冲突由提取流程报告。

Ren’Py 与已编译 TJS 目前只支持导出。Luca 需要匹配游戏方案；未知指令或不支持的变体会报错，保留源文件与已有输出。支持范围见[使用说明](../manual.zh-CN.md)。

普通桌面包需要对应架构的 [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0)；Store 和 Flatpak 包自带运行时。向微软 Partner Center 提交 **`garbro-1.1.2-store.msixupload`**，普通用户选择系统对应的安装包。Android APK 仍为使用开发签名的预览版，签名不同不能覆盖安装。下载后请核对 **SHA256SUMS**。

## English

- Ren’Py `.rpyc` / `.rpymc` exports to RPY / RPYM and compiled TJS2100 exports to TJS now run inside GARbro, without Python, unrpyc or tjs2dec.
- RPG Maker XP/VX/VX Ace Scripts export to one editable RGSS JSON file and compile back after editing. Ruby-only export remains available. Script IDs, order and names are retained; shared-string handling and Ren’Py return labels are corrected.
- Export Luca System `SCRIPT.PAK` to one JSON file and rebuild the complete archive with the selected game scheme. Eleven bundled profiles relocate recognized jumps after text-length changes. Schemes travel with the format database and can be maintained with SchemeTool.
- Updated English, Chinese, Russian and Japanese messages, CLI help, offline manuals and conversion screenshots. Removed Tool downloads and wrapper-specific detection. GUI and CLI share the native backends.
- Shinju no Yakata's METEOR01 support now uses the AVC database scheme, following the upstream approach. Dedicated parsing and filename rewriting were removed. General bounds checks remain; conflicting stored names use normal extraction conflict handling.

Ren’Py and compiled TJS currently support export only. Luca needs a matching game scheme. Unsupported instructions or variants fail while preserving sources and previous output; see the [manual](../manual.en-US.md).

Regular desktop packages require the matching [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0); Store and Flatpak include it. Upload **`garbro-1.1.2-store.msixupload`** to Microsoft Partner Center. Android APKs remain development-signed previews and cannot update installations signed with another key. Verify downloads using **SHA256SUMS**.

## Русский

- Экспорт Ren’Py `.rpyc` / `.rpymc` в RPY / RPYM и байткода TJS2100 в TJS теперь встроен в GARbro. Python, unrpyc и tjs2dec больше не нужны.
- Scripts из RPG Maker XP/VX/VX Ace экспортируются в один редактируемый JSON RGSS и собираются обратно после изменения. Экспорт только исходного кода Ruby сохранён. Сохраняются идентификаторы, порядок и имена; исправлена обработка общих строк и меток возврата Ren’Py.
- Luca System `SCRIPT.PAK` экспортируется в один JSON с последующей сборкой полного архива. Встроены 11 схем игр; распознанные переходы пересчитываются при изменении длины текста. Схемы обновляются с базой форматов и поддерживаются через SchemeTool.
- Обновлены сообщения, CLI, автономные руководства и снимки окна преобразования на четырёх языках. Удалены загрузка утилит и определение отдельных оболочек. GUI и CLI используют общие встроенные обработчики.
- Поддержка METEOR01 из Shinju no Yakata перенесена в схему AVC в базе по новому подходу upstream. Специальный разбор и переименование файлов удалены; общие проверки границ сохранены. Конфликты исходных имён обрабатывает обычное извлечение.

Ren’Py и скомпилированный TJS пока поддерживают только экспорт. Для Luca нужна подходящая схема игры. Неподдерживаемые инструкции и варианты вызывают ошибку, не меняя исходники и предыдущий результат. Подробнее — в [руководстве](../manual.ru-RU.md).

Обычным настольным пакетам нужна [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0) соответствующей архитектуры; Store и Flatpak включают её. Для Microsoft Partner Center предназначен **`garbro-1.1.2-store.msixupload`**. APK Android остаются предварительными сборками с ключом разработки и не обновляют установки с другой подписью. Проверяйте файлы по **SHA256SUMS**.

## 日本語

- Ren’Py の `.rpyc`／`.rpymc` → RPY／RPYM、コンパイル済み TJS2100 → TJS の出力を内蔵しました。Python・unrpyc・tjs2dec の追加インストールは不要です。
- RPG ツクール XP／VX／VX Ace の Scripts を 1 つの編集可能な RGSS JSON に出力し、編集後に再コンパイルできます。Ruby ソースのみの出力も残しています。番号・順序・名前を保持し、共有文字列と Ren’Py の戻り先ラベルの処理を修正しました。
- Luca System の `SCRIPT.PAK` を 1 つの JSON に出力し、ゲーム設定に従って完全なアーカイブへ再構築できます。11 種類の設定を同梱し、テキスト長の変更後に認識済みのジャンプ先を再計算します。設定は形式データベースと一緒に更新でき、SchemeTool でも管理できます。
- 4 言語の UI メッセージ、CLI ヘルプ、オフライン説明、変換画面の画像を更新しました。ツールのダウンロードと特定ラッパーの検出を削除し、GUI と CLI は同じ内蔵処理を使います。
- 『神樹の館』の METEOR01 対応を upstream の新方式に合わせて AVC データベース設定へ移しました。専用の解析・名前変更処理を削除し、共通の境界検査を保持します。元の名前が競合する場合は通常の抽出処理で報告します。

Ren’Py とコンパイル済み TJS は現在エクスポートのみ対応します。Luca にはゲームに合った設定が必要です。未対応の命令や形式はエラーとし、元ファイルと既存の出力を保持します。[使用説明](../manual.ja-JP.md)も参照してください。

通常のデスクトップ版には対応する [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0) が必要です。Store・Flatpak 版はランタイムを同梱します。Microsoft Partner Center には **`garbro-1.1.2-store.msixupload`** を提出してください。Android APK は開発用署名のプレビューで、署名が異なるインストールを更新できません。**SHA256SUMS** でダウンロードを確認してください。
