# GARbro-lazer 1.1.1

## 简体中文

- 新增封包功能：选中文件或目录后按 F3，选择归档格式和输出位置即可创建。可在封包前转换图像、音频或视频，并选择只打包转换后的文件；源文件保持不变。
- 新增内置脚本回编：支持 TSC → GSC、BSD/BPD → BGI、ASB JSON → ASB，以及文本 → NScripter / Utage DSM。这些回编不需要 Python 或外部编译器，继续兼容原来的可编辑格式。
- 转换窗口统一使用图像、音频、视频、脚本四个输出下拉框。“不转换脚本”位于脚本下拉框内；窄窗口会自动换行，文件列表优先保留文件名和大小。
- 升级至 .NET 11。界面、CLI 和解码进程继续共用应用文件；商店和 Flatpak 包自带运行时，其他桌面包需要先安装对应架构的 [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0)。
- 提供 Android 12 及以上的 ARM64、x64 **开发预览 APK**。支持浏览、预览、提取、创建归档及内置脚本回编；使用系统文件选择器授予访问权限。
- 补齐中英俄日界面、CLI 和离线使用说明。

桌面系统按设备选择 x64 或 ARM64；macOS 提供 Intel 和 Apple 芯片安装包。`garbro-1.1.1-store.msixupload` 用于微软 Partner Center 提交，普通用户无需下载。下载后使用 **SHA256SUMS** 核对文件。

Android 文件名含 `preview`，使用开发签名，后续签名改变时不能直接覆盖安装。Android 的视频预览取决于系统解码器；需要 FFmpeg 的媒体转换和可选桌面脚本工具暂不可用。Android 预览不代表已进入 F-Droid 或 IzzyOnDroid。

## English

- Create archives from selected files or folders with F3. Choose an archive format and destination, optionally convert images/audio/video before packing, and keep only converted media if desired. Source files stay unchanged.
- Built-in script recompilation supports TSC → GSC, BSD/BPD → BGI, ASB JSON → ASB, and text → NScripter / Utage DSM. These compilers require no Python or external compiler and keep the existing editable formats.
- Image, audio, video and script outputs now share one row of format selectors. “Do not convert scripts” is a dropdown choice. Narrow layouts wrap the selectors and prioritize filenames and sizes in the browser.
- Upgrade to .NET 11 while keeping GUI, CLI and decoder files shared. Store and Flatpak include the runtime; other desktop downloads require the matching [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0).
- ARM64 and x64 **Android development preview APKs** require Android 12+. Browse, preview, extract, create archives and recompile supported scripts using the system file picker for access.
- Updated English, Simplified Chinese, Russian and Japanese interfaces, CLI help and offline guides.

Choose x64 or ARM64 for your desktop; macOS downloads support Intel and Apple silicon. `garbro-1.1.1-store.msixupload` is for Microsoft Partner Center, not direct installation. Verify downloads with **SHA256SUMS**.

Android filenames contain `preview` and use development signatures: a later package signed with a different key cannot update that installation directly. Video preview depends on system codecs; FFmpeg-based media conversion and optional desktop script tools are unavailable on Android. These previews are not an F-Droid or IzzyOnDroid publication.

Файлы Android помечены `preview` и подписаны ключами разработки: пакет с другим ключом нельзя установить поверх прежнего. Видео использует системные кодеки; преобразование медиа через FFmpeg и внешние настольные средства сценариев на Android недоступны. Эти APK ещё не опубликованы в F-Droid или IzzyOnDroid.

## Verification / 验证

Native codec/encoding/worker/packing regressions, four-language and narrow-layout renders, the Android 12 x64 emulator flow (including 22 archive writers), and Windows MSIX install/upgrade/activation/uninstall checks passed before packaging. Release jobs build each architecture and perform short package checks. Android ARM64 is built and inspected; no real-device verification is claimed. macOS packages are built without tests.

打包前已完成定向回归、四语言与窄屏渲染、Android 12 x64 模拟器流程（包括 22 个归档写入后端）及 Windows MSIX 安装、升级、文件打开和卸载检查。发布时只进行安装包构建和简短核验。Android ARM64 仅构建并检查包结构，不声称已完成真机验收；macOS 只构建，不测试。

The shipped Wayland compatibility package is unchanged and its recorded checksum is checked. Its previously documented independent-rebuild hash mismatch remains; reproducible-build success is not claimed. 固定的 Wayland 补丁包保持不变并核对记录哈希；独立重建哈希仍有已记录的差异。
